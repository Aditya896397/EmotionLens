**Method.** 300 test faces were each turned into a 40-frame sequence with random rotation (+-6 deg), shift (+-3 px), scale (+-5 %), brightness (+-20 %) and Gaussian noise (sigma 8). The true expression is constant, so every label change is a flicker. **Limitation.** Real webcam footage also contains genuine expression changes; heavier smoothing reduces flicker but delays the response to real changes (latency is not measured here).
