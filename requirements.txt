# Compatibility notes:
#   * mediapipe 0.10.21 requires numpy<2 and protobuf<5  -> numpy is pinned to 1.26.4,
#     and tensorflow 2.17.1 is chosen because it also accepts numpy<2 / protobuf<5.
#   * mediapipe already depends on opencv-contrib-python. Do NOT also install
#     opencv-python: both provide the `cv2` module and overwrite each other.
#   * jax/jaxlib are pulled in by mediapipe; they are pinned so pip does not pick a
#     newer release that needs numpy>=2.
#   * TensorFlow >= 2.11 has no native-Windows GPU support. On Windows it runs on CPU
#     (fine for this project); use WSL2 if you want CUDA training.
